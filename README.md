## Android
### Free and Open Source Software (FOSS)
#### DetoxDroid
- [Repository](https://github.com/flxapps/DetoxDroid)
##### Features
* Grayscale Your Screen While Making Exceptions
* Automatically enter the "Do Not Disturb" mode
* Make Apps Disappear
* Break "Infinite Scrolling"
* Opt-out Ability
##### Cost
* Free!
##### Permissions
Network Required: NO
##### Authors Note
* Farhans grayscale application detection is currently better.
* I use this application.

#### Farhan - Brake phone addiction
- [Play Store](https://play.google.com/store/apps/details?id=ly.com.tahaben.farhan&hl=en-US)
- [Repository](https://github.com/tahaak67/Farhan)
##### Features
* Notifications Filter
* Infinite Scrolling Blocker
* Screen Grayscale
* Usage Check
##### Cost
* Free!
##### Permissions
Network Required: NO
ADB: Yes - for grayscale.
##### Authors Note
* Best open source grayscaling of applications.
* I use this application.

### Proprietary
#### 20 20 20 Eye Care
- [Play Store](https://play.google.com/store/apps/details?id=com.mexdesigns.app202020&hl=en-US)
- [Repository](https://github.com/tahaak67/Farhan)
##### Features
* Notifies you after 20 minutes to give your eyes a break.
* Starts countdown automatically when the screen is turned on.
* Configure the notification behavior the way you like.
* Start and stop the service manually.
* Confirm break in notification.
* AD free.
##### Cost
* Free!
##### Permissions
Network Required: NO
##### Editors Note
* Best application of its type.
* I use this application.

#### Digital Wellbeing (Google)
- [Play Store](https://play.google.com/store/apps/details?id=com.google.android.apps.wellbeing&hl=en_AU)
##### Features
* Get a daily view of your digital habits:
  * How frequently you use different apps
  * How many notifications you receive
  * How often you check your phone or unlock your device
* Daily app timers let you set limits for how much you use apps.
* Bedtime mode reminds you to switch off at night, setting a schedule to fade your screen to Grayscale while Do Not Disturb silences notifications for a good night’s sleep.
* Focus mode lets you pause distracting apps with a single tap so you can better focus your time. You can also set a schedule to turn on Focus mode automatically and reduce distractions while you’re at work, school, or home.
##### Cost
* Free!
##### Permissions
Network Required: Unknown
##### Editors Note
* Not supported on many devices and custom roms i.e. [GrapheneOS](https://grapheneos.org/)

#### Tasker
- [Play Store](https://play.google.com/store/apps/details?id=com.google.android.apps.wellbeing&hl=en_AU)
##### Features
* It is possible to set grayscale based on what application is open, time of day, etc.

##### Permissions
Network Required: No.
ADB: Yes - for grayscale.
##### Editors Note

### Built in Features
#### Color correction - Grayscale
##### Quick Action
##### Bind to Holding Down Volume Buttons
* Bind holding down both volume buttons at the same time to toggle grayscale on/off.
* To do this, go in Settings, then `Accessibility > Color and motion > Color correction`, and set it to grayscale.
* While still in the `Color correction` submenu, click `Color correction shortcut`, set it to `Hold both volume keys`, and toggle it on.
#### Developer Settings - Monochrome Mode
1. Enable Developer settings in Android (click build number 5 times).
2. Enable Monochrome Mode within Developer settings.
